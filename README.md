# OURA &amp; CO. — Interior Design

A single-page website for a fictional interior design studio, **OURA &amp; CO.** — *"We design the feeling of you."*

Built as clean, standard **HTML / CSS / JS** (no framework, no build step).

## Structure

```
index.html      # markup — hero, about, process, services, philosophy, concept, mood, contact
styles.css      # all styling, animations, and responsive breakpoints
script.js       # services accordion + contact-form handler
assets/img/     # photography (webp + jpg)
```

## Run locally

Open via a local server so relative paths resolve:

```bash
python -m http.server 8778
```

Then visit <http://localhost:8778/>.

## Sections

- **Hero** — split-image intro with animated reveal
- **About** — studio statement and stats (4 years · 20 designers · 62 projects)
- **Process** — Research · Concept · Detailing · Execute
- **Services** — interactive accordion of six offerings
- **Philosophy** — Balance · Comfort · Character
- **Interior Design** &amp; **Concept &amp; Mood** — showcase cards
- **Contact** — project inquiry form
